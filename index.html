Current architecture

Layer Component Responsibility
Client Claude Desktop Sends natural-language drafting requests and renders MCP tool results back to the user.
Transport MCP (stdio) Exchanges tool definitions and JSON tool calls/results between Claude Desktop and the Python server over standard input/output.
Server autocad_mcp/server.py Registers the MCP tool set (drawing info, entity queries, structure/geometry creation, layer management, deletion, undo, zoom) and routes each call to its handler.
Automation pywin32 COM bridge Marshals coordinates into VARIANT arrays and drives AutoCAD's COM object model (AddLine, AddCircle, AddText, AddArc, Layers), with retry/delay handling for COM timing issues.
Target application AutoCAD Executes the drawing operations and renders the resulting geometry in the active drawing.
